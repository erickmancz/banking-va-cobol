# Matriz de rastreabilidade COBOL → Java

Base de análise: `2784f6e47c3233bd4fc0680c6870d9bf6c1f9d02`, após merges #1 e #2. O repositório contém os fontes citados; não havia base Smart Engineering indexada. A análise do especialista `se-modernizer` foi estática, usando os fontes, e não constituiu execução nem aprovação de negócio. Fontes Java estão em `src/main/java/br/com/air/extrato/` e testes em `src/test/java/br/com/air/extrato/`. Números de linha referem-se à base; consulte os símbolos se houver alterações posteriores.

**Classificação:** E = execução diferencial local descrita no relatório de evidências; S = análise estática ou teste isolado Java, sem prova do ambiente host; H = hipótese ou pendência não comprovada. Mock não demonstra SQL/DB2. Ver `README.md`, `TRANSLATION_DECISIONS.md` e o relatório publicado nesta entrega para comandos, fixtures, hashes e resultados específicos.

## Limites de evidência e aceite pendente

O histórico relata 23 testes Java e golden COBOL local SHA-256 `58e51edc3af67a259159c866e4e024f34059eb8137720918d95ee617920e15a7`, 792 bytes, com cinco operações, primeira consumida. A evidência histórica e o golden não demonstram DB2, LOGFILE, IBM COBOL nem z/OS. Os resultados atuais, inclusive testes diferenciais adicionais e CI, constam no relatório de evidências desta entrega; não inferir paridade geral de casos não executados.

DB2/z/OS exigem autorização, endpoint de homologação e identidade somente leitura, snapshot sintético independente e estável apesar de WITH UR, testemunhas de filtros/ordem/NULL, parâmetros efetivos e versões de compilador, bind e driver. Não submeter `EXTCRDJ` original nem usar datasets de produção. Preservar datasets originais FB/LRECL 132, transferir binariamente sem RDW/newline, registrar CCSID, hashes e comparar bytes no mesmo encoding; conversão explícita por registro sem perda e com verificação de ida e volta quando o host for EBCDIC e Java ISO-8859-1. Comparar RC, logs e falhas/arquivos parciais separadamente. Divergências e rollback requerem aprovação de negócio/operação antes de qualquer troca de agendamento.
